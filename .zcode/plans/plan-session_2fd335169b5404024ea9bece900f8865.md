## 1. First principles
**Invariant across targets:** one FastAPI backend, one data/index layer, one API contract (`tests/contracts` + generated TS types, CI-pinned), one React codebase.
**What genuinely varies:**
| Axis | Desktop (Tauri) | Web (companion) |
|---|---|---|
| Delivery origin | `tauri://localhost` asset protocol | `http://<host>:8000/app/` served by FastAPI |
| API addressing | absolute `http://127.0.0.1:8000` | same-origin relative (`''`) |
| Principal | loopback ⇒ owner, no ceremony | paired cookie/bearer ⇒ owner; else 401 |
| Native capability | Tauri dialog (folder pick) | none; server-mediated or hidden |
| Form factor | wide, pointer | phone/tablet, touch (Phase 3) |
**Rule:** platform differences live in exactly two seams — `ui/src/platform/` (capabilities + detection) and `ui/src/api.ts` (transport). Nothing else may branch on platform.

## 3. Phase 0 — Desktop correctness (frontend)
**New `ui/src/platform/`:**
- `detect.ts`: `shell: 'tauri'|'browser'` computed once via `isTauri() || '__TAURI_INTERNALS__' in window`; `useFormFactor()` via `matchMedia('(max-width:767px)')` + `(pointer:coarse)` with resize subscription; `usePlatform()` ⇒ `{shell, isDesktopApp, formFactor, isMobile}`. Replaces `hooks/usePlatformDetect.ts` (2 consumers: `DynamicNotchSearch.tsx`, `ConnectSourceModal.tsx`; delete the hook). `hasNotch` comes only from `useNotch`.
- `capabilities.ts`: `platform.pickFolder()` (moves `pickDirectory.ts` logic; 3 callers migrate: `Spotlight`, `ConnectSourceModal`, `ImportWizard`; delete `pickDirectory.ts`), `platform.openExternal(url)`, `platform.revealInFileManager(path)` (both server-mediated today via existing `/api/actions/*`; the seam lets Tauri take over later).
**Transport (`ui/src/api.ts`, extend not fork):**
- `export function resolveApiBase()`: `VITE_API_URL` if *defined* (empty string = same-origin, so `??` semantics not `||`), else `'http://127.0.0.1:8000'`. `export const API_BASE`.
- `export function apiUrl(path)` and `export async function apiFetch(path, init)` — fetch wrapper applying `API_BASE`, `X-User-ID`, `Authorization`/cookie, `credentials:'include'` when same-origin. One transport, two faces (axios + fetch) sharing base and headers.
- `export const mediaUrl = { thumbnail, video, file, faceCrop }` factory — all media URLs through one builder (identity consistently applied; `getImageUrl/getVideoUrl/getFileUrl` become thin wrappers).
- Migrate every Family A/B call site (~25 files listed in exploration: `ActionService`, `defaultActions`, `BulkActionsService`, `useLiveMatchCount`, `pages/People|PersonDetail|Singletons|LowConfidence|AllFacePhotos`, `components/people/*`, `FaceClustering`, `OCRSearch`, `CodeSplitting`, `TauriIntegration`, `PrivacyDashboard`, `ModalSystem`, `IntentRecognition`, `PerformanceDashboard`) to `apiFetch`/`apiClient`/`mediaUrl`. Lint guard: eslint `no-restricted-syntax` rule banning `fetch('/api` and inline `localhost:8000` literals outside `api.ts`.
- `ApiStatusBanner`: distinguish unreachable vs CORS/401 (fetch `TypeError` + status) — honest copy.
**Tests (vitest):** `resolveApiBase` env matrix; `platform/detect` with mocked `__TAURI_INTERNALS__`; `apiFetch` header injection. Existing 35 stay green.

## 4. Phase 1 — Web build target + same-origin serving
**UI:** `ui/.env.web` (committed, non-secret): `VITE_API_URL=`. `vite.config.ts`: `base: mode==='web' ? '/app/' : '/'`; `package.json`: `build:web = tsc -b && vite build --mode web --outDir dist-web` (desktop `build`/`dist` untouched so `tauri.conf.json` is unchanged). `MainRouter`: `<Router basename={import.meta.env.BASE_URL}>`.
**Backend (`server/config.py` + `server/main.py`):** `HOST="127.0.0.1"`, `PORT=8000` (replace hardcode; `dev-restart.sh` passes `BACKEND_PORT`→`PORT`); `SERVE_UI=True`, `UI_DIST_DIR=BASE_DIR/ui/dist-web`; mount `SPAStaticFiles` (StaticFiles subclass: 404→`index.html`) at **`/app`** when the dir exists. Rationale for `/app` prefix over a root catch-all: API routes are top-level (`/search`, `/browse`…) so a catch-all would turn API typos into 200 HTML and would add a contract route; a mount adds none. `GET /` keeps its current behaviour (dev script health-waits on it).
**Default host change is deliberate:** loopback-only until the owner enables LAN (`HOST=0.0.0.0`) — which Phase 2 makes safe. Fix `nginx.conf` prefix note in docs (Docker path stays audit-only).
**Tests (pytest):** settings defaults; `/app/` serves index; deep link `/app/people` falls back to index; assets served; mount absent when dir missing. Contract parity unchanged (mounts not in OpenAPI).

## 5. Phase 2 — Trust boundary: principal resolver + pairing
**`server/principal.py`:** `Principal(id, kind='owner', via: 'loopback'|'cookie'|'bearer')`; `resolve_principal(request)`: loopback peer (`127.0.0.1/::1`; honour `X-Forwarded-For` only when new `TRUST_PROXY=False` is true) ⇒ owner; else valid session token from cookie `ps_session` or `Authorization: Bearer` ⇒ owner. Tokens reuse `server/auth.py` `create_jwt/verify_jwt` with a new `SESSION_SECRET` (auto-generated once into `DATA_DIR/session.key` so desktop needs zero config). Owner id = `"default_user"` to preserve all existing privacy-control/data keys.
**`PrincipalMiddleware` (pure ASGI, one place, not 53 router edits):** exempt `/`, `/health`, `/pair/*`, `/app/*`, and `/docs|/openapi.json` when DEBUG; unresolved ⇒ 401 JSON; sets `request.state.principal`. `user_id_from_request` returns `principal.id` first (header/query become advisory). TestClient compatibility: treat literal `testclient` peer as loopback only under `PHOTOSEARCH_TEST_MODE`/pytest (same env pattern `deps.py` already uses); gate tests use `TestClient(app, client=("10.0.0.5", 1))`.
**Pairing router `server/api/routers/pairing.py`:** `POST /pair/start` (loopback only) ⇒ one-time 6-digit code + URL, 5-min TTL, stored in `DATA_DIR` sqlite; `POST /pair/complete {code}` ⇒ sets `ps_session` cookie (HttpOnly, SameSite=Lax, Secure if https) + returns bearer; `POST /pair/revoke` (loopback) rotates `SESSION_SECRET` ⇒ all devices out; `GET /pair/status`. Because `<img>` requests carry the cookie same-origin, **no signed-URL flip is needed** for the companion; signed URLs stay for cloud/hybrid.
**Rate limiting:** make the dead `main.py:104-107` counters a real middleware using existing `RATE_LIMIT_*` settings, non-loopback only.
**UI:** `platform/session.ts` + `/pair` route (code entry; also accepts `?code=`); Settings → "Connect a device" panel (loopback-only, shows code + URL); `apiFetch`/axios 401 interceptor ⇒ navigate to `/pair` in browser shell (desktop never 401s).
**Tests:** principal matrix (loopback/cookie/bearer/none/exempt); pairing lifecycle incl. revoke and TTL expiry; media route 401 for unpaired LAN peer, 200 after pairing; S2 proof: assert 401 *before* adding the cookie. Regenerate `tests/contracts/*.json` for the 4 new routes (parity gate) and `npm run generate:api-types`.
